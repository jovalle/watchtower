## Blockers Fixed

- Supplied the dark app's default text color and explicit foregrounds for dark poster cards and badges.
- Removed duplicate focus targets from editable fields; enabled Down-to-Continue and keyboard Done for server entry.
- Hid the library drawer on player destinations and explicitly assigned focus to player controls or the player root when controls hide.
- Moved native API response-body reads to `Dispatchers.IO`. The real Home response exposed `NetworkOnMainThreadException`; a delayed-body instrumentation regression reproduces the former failure. Temporary diagnostic logging was removed.
- Added isolated fixture pairing support and an XML assertion for fullscreen player focus. The fixture preload refuses a data directory outside its fixed harness path and accepts only the synthetic identity.

## Limits

Physical TV hardware, HDMI audio passthrough, HDR display behavior, and release-build device execution were not checked. This pass does not cover every catalog action or long-duration playback.
